## 4. Implementation (só M003)

`src/engine/authority.ts` (~200 linhas): `Untrusted<T>` + envelope + caps;
`AuthorityKernel<S>` (sole writer, sessões server-side, dedupe por
requestId, freeze-before-commit = atomicidade, plain-data guard, audit log).
`src/engine/harness.ts`: `noop` + `harvest` (yield de tabela server-side;
campos outcome do cliente deliberadamente nunca lidos).

Garantias provadas: (1) clientes não escrevem estado (freeze + API);
(2) spoof impossível (binding server-side); (3) outcomes 100% servidor;
(4) exactly-once por requestId; (5) transições atómicas; (6) auditoria total.

Decisões: noop bumpa revision (audit regista tudo); rejeições gravadas,
faltas/erros não (retry honesto); sessões FORA do estado (random fora do
determinismo — testado); estado tem de ser plain-data (guard mecânico);
`result.applied === true` estrito; sync+single-thread (constraint p/ M071).
