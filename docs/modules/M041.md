## What it does

`sim/strategy-drill.ts` (run: `npm run sim:strategy`, default 20
games × 60 steps, seeds 1000–1019) plays real deterministic
`Match`es through the genuine engine: triples pre-seeded, units,
L1 cities, funded stockpiles. Bots dispatch commission / flips /
build / upgrade / noop; the engine outcome is the legality oracle.
After EVERY applied dispatch the harness checks the 7 wiring
invariants against the LIVE snapshot:

1. Query-count coherence: `assessmentOf` units/commanders/active
   equal live-snapshot counts, both holders.
2. Independent military recompute: drill-side loop over snapshot
   units + direct `DRILL_UNITS` damage lookups vs
   `query.military.totalHp/totalDamage`.
3. Stances valid + roster-ordered; `postureOf` majority sits in
   the distribution argmax set (order-free; tie-break is M039's
   unit-proven business, not the drill's).
4. Economy deep-equal: query stockpile/buildings/cityLevel vs
   raw snapshot reads (zeros/level-1 when absent).
5. `ai.assessment` newcomer shape: priority low, player p1/p2,
   military numbers finite, stockpile record, cityLevel number,
   commanders counts numbers, `avgEffective` all-traits 0–100
   when present, stances array of valid `{id, stance}`.
6. Beat cliché: applied `city.upgrade` emits exactly +2 facts
   (both holders), any other applied type exactly +0.
7. Zero `system.event-fault` anywhere + snapshot JSON round-trip.
